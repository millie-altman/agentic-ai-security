# Agentic AI Security Research

This directory contains technical research and working notes related to Agentic AI security.

Research topics may include:

* Prompt injection
* Indirect prompt injection
* Excessive agency
* Tool abuse
* Agent identity
* Agent authorization
* Model Context Protocol security
* Memory poisoning
* RAG poisoning
* Multi-agent security
* AI red teaming
* Secure agent architecture
* Agent observability
* Emerging AI attack techniques

Research notes may later support labs, threat models, security experiments, or full portfolio projects.

## Research Approach

Where possible, research should answer:

1. What is the security issue?
2. Why does it exist?
3. What asset is at risk?
4. What would exploitation look like?
5. What controls could reduce the risk?
6. How could the control be tested?
7. How does this apply specifically to agentic systems?

Sources should prioritize official documentation, standards, established security organizations, and reputable technical research.
