# Course Labs

This directory contains hands-on labs completed while studying Agentic AI
engineering, AI security, and related technologies.

Course exercises are documented for educational purposes and may be expanded
with independent security analysis and defensive experimentation.

## Lab Methodology

Where appropriate, labs will be evaluated using the following questions:

1. What capabilities does the agent have?
2. What data can the agent access?
3. What tools can the agent invoke?
4. What trust boundaries exist?
5. What happens if the agent receives malicious instructions?
6. Could tool output manipulate agent behavior?
7. What actions should require human authorization?
8. What security events should be logged?
9. What data should the agent never access?
10. What defensive controls could reduce the identified risks?

Course labs may later be extended into independent security experiments
or portfolio projects.
