# Security Policy

This repository contains educational security research involving Agentic AI systems, AI security testing, threat modeling, and controlled adversarial experimentation.

All testing documented in this repository is intended for:

* Systems I own
* Systems I am explicitly authorized to test
* Purpose-built laboratory environments
* Synthetic or non-sensitive data

Security examples, vulnerable agents, malicious prompts, and adversarial scenarios are created for educational and defensive research purposes.

## Sensitive Information

This repository should never contain:

* API keys
* Authentication tokens
* Passwords
* Private credentials
* Proprietary company information
* Personal sensitive data
* Production secrets

Secrets should be stored using appropriate environment variables or secret-management mechanisms and excluded from version control.

## Reporting a Repository Security Issue

If a security issue is discovered in code contained in this repository, please open a GitHub issue describing the problem without including sensitive credentials or exploitable secrets.
