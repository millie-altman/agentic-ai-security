# Evidence Rule

A skill should not be marked as **Portfolio Demonstrated (Level 4)** simply because I completed a course covering the topic.

Level 4 requires independent evidence such as:

* Original code
* Security testing
* Threat models
* Architecture documentation
* Research
* Analysis
* Control implementation
* Governance documentation
* Test results
* Demonstrated project outcomes

The goal is not to maximize the numbers.

The goal is for the matrix to accurately reflect what I can demonstrate.
